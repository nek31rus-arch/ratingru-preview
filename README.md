# РейтингРу — тестовый сайт

Утверждённая v9: общие ссылки для компьютеров, планшетов и телефонов. Главная — index.html, каталог — category.html, пример статьи — article.html.

Данные, участники и фотографии демонстрационные; комментарии сохраняются только в браузере. Поисковая индексация отключена метатегами noindex.
