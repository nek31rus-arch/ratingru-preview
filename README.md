# РейтингРу — тестовый сайт

Утверждённая v14.1. Общие адреса для компьютеров, планшетов и телефонов:

- Главная — index.html
- Все разборы — category.html
- Пример статьи — article.html
- Методика — methodology.html
- О проекте и контакты — about.html
- Проект документа об обработке данных — privacy.html
- Страница ошибки — 404.html

Мобильная форма контактов раскрывается под выбранной темой. Сообщение можно подготовить и скопировать; серверная отправка не подключена. Данные участников, оценки и фотографии демонстрационные; комментарии сохраняются только в браузере. Неизвестные сведения об издателе, контактах и финансировании не придуманы; формула оценки ещё требует согласования.

Поисковая индексация запрещена метатегами noindex, nofollow. Сайт публичный. GitHub Actions проверяет и публикует site/ после отправки утверждённых изменений в main.

Адрес: https://nek31rus-arch.github.io/ratingru-preview/
