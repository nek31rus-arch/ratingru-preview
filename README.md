# РейтингРу — тестовый сайт и структура v27.1

Публичный предпросмотр: https://nek31rus-arch.github.io/ratingru-preview/
Структура сайта: https://nek31rus-arch.github.io/ratingru-preview/structure.html

Основа страниц — утверждённая v24.1. По прямой команде владельца 02.11.2026 добавлены конструктор структуры и ссылка на него в шапке. Конструктор содержит 9 страниц, отдельные блоки, общие данные рейтинга, CSS/JS-редакторы, изображения, шрифты, скачивание HTML, ZIP статического сайта и Gutenberg-плагина.

## Страницы
- Главная — index.html
- Все рейтинги — category.html
- Пример статьи — article.html
- Новости — news.html
- Пример новости — news-item.html
- Методика — methodology.html
- О проекте и контакты — about.html
- Проект документа об обработке данных — privacy.html
- Страница ошибки — 404.html
- Структура сайта — structure.html

В конструкторе изменения остаются в копии пользователя. Они не отправляются в GitHub и не меняют публичные страницы. Для сохранения используйте скачивание HTML; для переноса — ZIP и копирование блоков. Плагин Gutenberg подготовлен, но не проверен на реальном WordPress. Комментарии и формы демонстрационные; серверная отправка не подключена. Город выбирается пользователем, определения по IP нет. Данные участников и оценок условные.

Каждая HTML-страница содержит noindex, nofollow. Это публичный сайт. GitHub Actions проверяет точный список разрешённых файлов и публикует только site/ после отправки в main. Следующее обновление требует нового утверждения и прямой просьбы опубликовать. Откат — обычным revert-коммитом предыдущего релиза; принудительную перезапись истории не использовать.

Исправления v27.1: сохранённый HTML восстанавливает выбранную страницу/экран без дубликатов списка; ZIP Gutenberg включает текущие изменения CSS/JS и шаблонов.
