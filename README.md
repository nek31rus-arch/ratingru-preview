По прямой команде владельца добавлены выбранные каталог блога и полезная статья, ссылка «Блог» в шапках, оба шаблона в конструкторе блоков и короткая инструкция рядом с блоком тематических рейтингов. Предыдущие страницы сохранены. Конструктор содержит 11 типов страниц, CSS/JS, изображения, шрифты и выгрузки HTML, статического сайта и тестового комплекта Gutenberg.

В блоге одна готовая инструкция, остальные карточки явно обозначены как темы будущих материалов. Тематические рейтинги в инструкции ведут на страницы-примеры без компаний; реальная автоматическая выборка записей WordPress и определение города по IP не подключены. Gutenberg-комплект не проверен на работающем WordPress. Комментарии и формы остаются демонстрационными.

Правки в конструкторе изменяют только копию пользователя. Они не сохраняются на публичном сайте; для переноса скачайте HTML или комплект. Во всех страницах сохранён noindex, nofollow. Это публичный сайт, запрет индексации не ограничивает доступ.

GitHub Actions проверяет точный список публичных файлов и публикует только site/ после отправки в main. Следующая публикация требует нового утверждения и прямой команды владельца. Предыдущая точка отката: v27.1-verified-2026-11-02. Откат выполняется отдельным обратным коммитом без принудительной перезаписи истории.
