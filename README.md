# РейтингРу — тестовый сайт

Утверждённая v13: общие ссылки для компьютеров, планшетов и телефонов. Главная — index.html, каталог — category.html, пример статьи — article.html.

Досье выбора с тремя разделами, закреплённая шапка и поиск города. Данные, участники и фотографии демонстрационные; комментарии сохраняются только в браузере. Поисковая индексация запрещена метатегами noindex, nofollow.

GitHub Actions публикует проверенную сборку из site/ после изменений в main. Адрес сайта: https://nek31rus-arch.github.io/ratingru-preview/
