# РейтингРу — тестовый сайт

Утверждённая v21.1. Единое название разделов «Рейтинги», каталог «Все рейтинги», новости со сводкой и тематическими подборками. Заголовки рейтингов в новости подчёркиваются красной линией при наведении и клавиатурном фокусе. ПК, планшет и телефон открываются по одинаковым адресам.

- Главная — index.html
- Все рейтинги — category.html
- Пример статьи — article.html
- Новости — news.html
- Пример новости — news-item.html
- Методика — methodology.html
- О проекте и контакты — about.html
- Проект документа об обработке данных — privacy.html
- Страница ошибки — 404.html

Новости и рейтинги содержат явно обозначенные примеры для проверки интерфейса. Числа Топ-N в новых подборках демонстрационные. Подборка учитывает тему и выбранный город; определения города поIP иCMS нет. Поиск работает по локальному набору. Комментарии сохраняются в браузере, серверная отправка форм и модерация не подключены. Контакты, неизвестные сведения об издателе и окончательная методика не выдуманы.

Во всехHTML — noindex, nofollow. Это публичный сайт. GitHub Actions проверяет allowlist и публикует только site/ после отправки утверждённых изменений вmain. Следующие публикации требуют прямого разрешения владельца.
