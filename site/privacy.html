О чём этот документ

Эта страница описывает работу текущего прототипа РейтингРу. Это проект документа, а не окончательная политика действующего сервиса.

Перед запуском реальных форм необходимо указать оператора, цели и правовые основания обработки, сроки хранения, получателей данных и рабочий контакт для обращений. Эти сведения пока не подтверждены.

Название РейтингРу — название проекта. Оно само по себе не заменяет сведения об операторе.

Какие сведения используются

Выбранный город

Может сохраняться в этом браузере, чтобы повторно использовать его в поиске.

Комментарий в образце статьи

Имя и текст сохраняются локально. Почта запоминается вместе с именем только при выборе соответствующей настройки.

Форма связи с редакцией

Имя, почта и сообщение используются для предпросмотра текста в открытой вкладке. Форма не отправляет их редакции и не сохраняет черновик после перезагрузки.

Где остаются данные

Локальные комментарии и запомненные настройки находятся в хранилище браузера для адреса, на котором открыт прототип. Они не становятся общей базой комментариев и не появляются у других посетителей.

Локальная копия может оставаться до её удаления пользователем или очистки данных браузера. Режим инкогнито и настройки браузера могут ограничивать сохранение.

Что видит площадка размещения

При открытии страницы браузер обращается к серверу, с которого загружаются файлы сайта. Площадка размещения может обрабатывать технические сведения о запросах.

Для опубликованной тестовой версии используется GitHub Pages. GitHub сообщает, что IP-адрес посетителя регистрируется для целей безопасности. Это отдельный процесс площадки размещения.

Описание GitHub Pages

Как удалить локальные сведения

Комментарий можно удалить рядом с ним в образце статьи. Чтобы убрать запомненные имя и почту, снимите соответствующую отметку в форме комментария.

Кнопка ниже очищает выбранный город, комментарии и запомненные имя и почту этого прототипа в текущем браузере. Она не удаляет сведения, которые могут обрабатываться площадкой размещения.

Обращения и обновления

Рабочий канал для запросов по данным должен быть указан вместе со сведениями об операторе перед запуском реального сбора данных. Пока публичная почта не добавлена, форма связи работает только как предпросмотр.

После определения реальных процессов документ будет уточнён. При изменении целей, состава данных или сервисов обработки потребуется пересмотреть и его содержание.
